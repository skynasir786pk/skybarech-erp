# Engineering rules

1. PIN is exactly four ASCII digits in every client and API flow.
2. Never expose an editable production API URL to shop customers.
3. Do not replace the single Compose splash with an additional native splash.
4. Preserve Hostinger API compatibility when changing Android or Desktop clients.
5. Server role permission is authoritative; client UI must not grant blocked operations.
6. Validate Android XML, JavaScript syntax and desktop PIN tests before packaging source.
